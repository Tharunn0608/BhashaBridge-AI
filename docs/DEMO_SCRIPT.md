# 60-second demo script

**Before recording:** run the live tests once, set `GNANI_API_KEY`, open `http://127.0.0.1:5000/dashboard`, choose a quiet room, set language to your demo language, and clear the conversation. Do one rehearsal so Gnani warms up. Record the screen with audio from your speakers and microphone.

| Time | On screen | Say / do |
|---|---|---|
| 0:00–0:08 | Landing page | "Many students think in Kannada, Hindi, Tamil or Telugu, but most digital help is English-first. BhashaBridge AI changes that with voice." |
| 0:08–0:15 | Click **Start conversation**; point to the language selector and the green API status pill | "Pick your language. The status pill shows the Gnani services are live." |
| 0:15–0:27 | Select **Kannada**, tap the mic, speak one sentence (for example, how to prepare for exams) | Speak naturally in the language. Watch the recording animation. |
| 0:27–0:34 | Transcript appears as your message | "Gnani **Prisma** has converted my speech to text, in Kannada script." |
| 0:34–0:42 | Reply appears with its source label | "The reasoning layer writes a helpful answer in the same language. Every answer is labelled so you know where it came from." |
| 0:42–0:50 | Reply plays aloud; tap **Replay** | "Gnani **Timbre** speaks it back in a natural voice. I can replay or copy it." |
| 0:50–0:56 | Switch to **Student help**; search "scholarship" | "There is also a searchable student FAQ, clearly marked as demo data for each college to replace." |
| 0:56–1:00 | Back to landing page | "BhashaBridge AI: breaking language barriers through voice intelligence. Built with Gnani Prisma and Timbre." |

**Tips:** keep the spoken question short (under 10 seconds); if a transcription is slightly off, say so honestly and retry, since a real demo beats a perfect one. Do not show your `.env` file or API key on screen.
